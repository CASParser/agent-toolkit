The `UnifiedResponse` schema is returned by all CAS parsing endpoints (`/v4/smart/parse`, `/v4/cdsl/parse`, `/v4/nsdl/parse`, `/v4/cams_kfintech/parse`).

## Overview

Regardless of the source (CDSL, NSDL, CAMS, KFintech), all CAS parsing endpoints return the same unified structure. This consistency makes it easy to integrate CAS Parser into your application.

**Top-level structure:**

```json
{
  "meta": { ... },
  "investor": { ... },
  "summary": { ... },
  "demat_accounts": [ ... ],
  "mutual_funds": [ ... ],
  "insurance": { ... },
  "nps": [ ... ]
}
```

## Key Fields

### `meta`
Metadata about the CAS statement itself — type detected, statement period, generation timestamp.

### `investor`
Investor details extracted from the CAS — name, PAN, email, mobile, address.

### `summary`
Portfolio-level summary with total value and account counts across all asset classes.

### `demat_accounts`
Array of demat accounts (NSDL/CDSL) with equities, bonds, mutual funds, government securities, and AIFs.

### `mutual_funds`
Array of mutual fund folios (non-demat) with schemes, transactions, and gains.

### `insurance`
Life insurance policies (CAMS/KFintech only).

### `nps`
National Pension System accounts.
