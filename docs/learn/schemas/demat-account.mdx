The `DematAccount` schema represents a single demat account (NSDL or CDSL) extracted from a CAS statement.

## Overview

Demat accounts hold various asset classes:
- **Equities** — Stocks, ETFs
- **Corporate Bonds** — Company bonds with coupon rates
- **Government Securities** — Sovereign Gold Bonds, T-Bills, G-Secs
- **AIFs** — Alternative Investment Funds
- **Demat Mutual Funds** — Mutual funds held in demat form

## Key Fields

### Account Identifiers

| Field | Description |
|-------|-------------|
| `demat_type` | `NSDL` or `CDSL` |
| `dp_id` | Depository Participant ID |
| `dp_name` | DP name (e.g., "ZERODHA", "ICICI DIRECT") |
| `client_id` | Client ID / Account number |
| `bo_id` | Beneficiary Owner ID (CDSL only, 16-digit) |

### Holdings

The `holdings` object contains arrays of different asset types:

```json
{
  "holdings": {
    "equities": [...],
    "corporate_bonds": [...],
    "government_securities": [...],
    "aifs": [...],
    "demat_mutual_funds": [...]
  }
}
```

Each holding type has its own schema — see related schemas below.

### Linked Holders

For joint accounts, the `linked_holders` array contains additional account holder details:

```json
{
  "linked_holders": [
    {
      "name": "Jane Doe",
      "pan": "FGHIJ5678K"
    }
  ]
}
```

### Additional Info

CDSL accounts include extra metadata in `additional_info`:

| Field | Description |
|-------|-------------|
| `bo_status` | Account status (Active, Dormant, etc.) |
| `bo_type` | Account type (Individual, Corporate, etc.) |
| `bsda` | Basic Services Demat Account flag |
| `nominee` | Nominee details |
| `email` | Email registered with DP |

## Usage

Access demat accounts from the parsed response:

```python
response = requests.post(
    "https://api.casparser.in/v4/smart/parse",
    headers={"x-api-key": "YOUR_API_KEY"},
    files={"file": open("cas.pdf", "rb")},
    data={"password": "ABCDE1234F"}
)

data = response.json()

for account in data['demat_accounts']:
    print(f"DP: {account['dp_name']}")
    print(f"Value: ₹{account['value']:,.2f}")
    print(f"Equities: {len(account['holdings']['equities'])}")
```
