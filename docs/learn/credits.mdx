Every billable API call consumes **credits**. One credit is the cost of parsing one CAS PDF — everything else is priced relative to that.

This page lists the per-operation cost. For plans and rupee pricing, see [casparser.in/pricing](https://casparser.in/pricing).

<Note>
  **Failed operations cost nothing.** If a call returns a `4xx` or `5xx`, no credits are deducted. You are only billed for a successful result.
</Note>

## Parsing

Extract structured data from CAS PDFs.

| Operation | Endpoint | Credits |
|---|---|---|
| Smart Parse (auto-detects format) | `POST /v4/smart/parse` | **1.0** |
| CAMS / KFintech parser | `POST /v4/smart/parse` | **1.0** |
| CDSL parser | `POST /v4/smart/parse` | **1.0** |
| NSDL parser | `POST /v4/smart/parse` | **1.0** |
| Contract note parser | `POST /v4/contract_note/parse` | **0.5** |

<Tip>
  All CAS formats cost the same and share one endpoint. Call `/v4/smart/parse` and let the server pick the engine — there is no cheaper path by naming the format yourself.
</Tip>

## Retrieval

Get CAS documents from the source.

| Operation | Endpoint | Credits |
|---|---|---|
| CAS Generator (email mailback) | `POST /v4/generate` | **0.5** |
| CDSL OTP Fetch | `POST /v4/cdsl/fetch` | **0.5** |
| Email inbox pull (Gmail, Outlook, Zoho) | `POST /v4/inbox/cas` | **0.2** per pull |
| Inbound email (forwarded statements) | `POST /v4/inbound-email` | **0.2** per email received |
| Portfolio Links submission | *(no-code portal)* | **0.2** per submission |

## Identity

Verify investor identity, KYC status, and adviser registration.

| Operation | Endpoint | Credits |
|---|---|---|
| KYC PAN status (5 KRAs) | `POST /v1/kyc/pan/status` | **0.25** |
| KYC DigiLocker result | `POST /v1/kyc/digilocker/result/{session_id}` | **0.25** per call |
| SEBI registration verification | `POST /v1/verify/sebi` | **0.25** |
| AMFI distributor (ARN) verification | `POST /v1/verify/mfd` | **0.25** |

<Warning>
  A registry lookup that finds nothing is still a **successful, billed** call. `verified: false` with `registration_status: NOT_FOUND` returns `200` and costs 0.25. Only genuine upstream failures (`5xx`) are free.
</Warning>

## Free operations

These never consume credits:

| Operation | Endpoint |
|---|---|
| Check credit balance | `POST /v1/credits` |
| Generate an access token | `POST /v1/token` |
| Email OAuth connect / status / disconnect | `POST /v4/inbox/connect`, `/status`, `/disconnect` |
| DigiLocker account lookup + session start | `POST /v1/kyc/digilocker/account-lookup`, `/session` |
| Create or list an inbound email address | `POST /v4/inbound-email`, `GET /v4/inbound-email` |
| Poll inbound email files | `GET /v4/inbound-email/{id}/files` |
| Usage reporting | `POST /v1/usage`, `POST /v1/usage/summary` |
| Any sandbox call | any endpoint with `sandbox-with-json-responses` |

## Check your balance

```bash
curl -X POST https://api.casparser.in/v1/credits \
  -H "x-api-key: YOUR_API_KEY"
```

The response also lists the features enabled on your plan, so you can gate your own UI on what the key can actually call.

## Test without spending credits

Use `sandbox-with-json-responses` as your API key. It returns realistic sample responses for every endpoint and never deducts credits. See [Sandbox](/resources/sandbox).
