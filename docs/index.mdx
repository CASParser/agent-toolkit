## How it works

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   Input         │     │   CAS Parser    │     │   Output        │
├─────────────────┤     ├─────────────────┤     ├─────────────────┤
│ • PDF Upload    │────▶│ • CDSL Parser   │────▶│ • Equities      │
│ • Gmail Import  │     │ • NSDL Parser   │     │ • Mutual Funds  │
│ • CDSL OTP      │     │ • CAMS Parser   │     │ • Bonds & AIFs  │
│ • KFintech Gen  │     │ • KFintech      │     │ • NPS/Insurance │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                        │
                                                        ▼
                                                 Unified JSON
```

**One API, any CAS format.** Send a PDF, get structured JSON. Works with all Indian depositories and registrars — CDSL, NSDL, CAMS, KFintech.
